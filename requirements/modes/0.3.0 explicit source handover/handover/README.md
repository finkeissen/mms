# Handover
## Explicit, Versioned Transfer of Artifacts into MMS

### Purpose
Artifacts may be transferred into MMS only via **explicit, versioned, traceable handover**.

This directory defines the minimal discipline and format required for handover.
Handover does not confer epistemic validity.

---

## Files
- `manifest.schema.json` — machine-readable schema
- `manifest.example.json` — minimal example
- `README.md` — discipline and meaning

---

## Core Rules
- No implicit inheritance of:
  assumptions, boundaries, normativity, authority.
- Every handover must state:
  source, version, assumptions, and STOP/limits.
- Missing information is allowed.
- Conflicts are allowed.
- STOP is allowed and must be preserved.
