# MMS 0.1.1 – Aktiver Entwicklungscontainer

Dies ist die aktuelle Arbeitsversion des Matrix-Management-Systems (MMS).

## Inhalt

- docs/ – Konzepte, Protokolle, Metamodell (noch in Entwicklung)
- data/ – Domains, Probleme, Wissenseinträge (leer)
- engine/ – Skripte zur Ausführung der Protokolle
- schema/ – JSON-Schemas (Platzhalter)
- exports/ – Ausgaben
