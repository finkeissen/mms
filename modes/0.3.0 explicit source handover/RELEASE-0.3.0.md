# MMS — Release 0.3.0
## Explicit Handover & Research-0.4 Compatibility

### Summary
Version 0.3.0 introduces a **formal, explicit handover mechanism** for artifacts and clarifies
compatibility with the **research-program methodological baseline (0.4)**.

MMS remains **non-authoritative**: outputs are system artifacts, not truth claims.

---

### What is new in 0.3.0
- A versioned **handover manifest** format for importing artifacts into MMS
- Explicit **compatibility statement** to research-program 0.4 (methodological layer)
- Clearer separation of:
  - research assumptions and boundaries
  - MMS system-scoped integration artifacts
- Stronger “fail-closed” discipline:
  STOP and underdetermination remain first-class outcomes

---

### What 0.3.0 is not
- Not a research program
- Not a truth/validity authority
- Not a decision engine
- Not a governance system

---

### Compatibility
- Compatible with: **research-program 0.4** (evaluation & responsibility discipline)
- Conceptual baselines may still be sourced from research-program 0.3 snapshots,
  but evaluation and handover discipline follows 0.4.

---

### Status
- Version: **0.3.0**
- Scope: system-level integration, explicit handover, traceability
- Authority: none
