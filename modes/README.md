# modes/ (Archive)

This directory is a **historical exploration archive**.

It contains prior iterations, experiments, and prototypes that led to the
current MMS architecture.

Important:
- `modes/` is **not** part of the canonical MMS execution model.
- New development must happen in:
  - `docs/`
  - `schemas/`
  - `profiles/`
  - `pipelines/`
  - `runs/`
  - `kernel/`

We keep `modes/` for traceability and learning,
but we do not evolve it further.
